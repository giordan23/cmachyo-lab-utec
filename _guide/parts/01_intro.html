Del asesor de ventas al analista de riesgos: enrutamiento semántico, RAG y aprobación humana

Un asesor de ventas conversa con el sistema sobre las reglas de los productos de crédito. Jev decide qué hacer con cada mensaje; un agente especialista en riesgo calcula, revisa las reglas de un PDF de políticas con RAG y propone un dictamen con OpenAI; cuando hace falta, la conversación escala: un analista humano aprueba o rechaza en una web simple y la decisión vuelve al chat del asesor. Todo medido con Prometheus y Grafana.

1 · EnrutarClasificar la intención del asesor con Jev (TypeSafe), con umbral de confianza y respaldo si la API falla.
2 · ConversarRAG conversacional sobre un PDF de reglas: citas exactas (artículo + página), preguntas de seguimiento y datos personales enmascarados.
3 · Decidir con controlCálculos en código, guardas deterministas y un LLM que solo puede endurecer el dictamen.
4 · AprobarHumano en el circuito: segregación de funciones, comentario obligatorio y decisiones atómicas.
5 · ObservarMétricas de negocio, de calidad y de costo en Prometheus; un tablero de Grafana listo.

Qué es real y qué es simulado

PiezaEstado
Datos y reglasFicticios. El PDF es de una entidad inventada (Caja Demo Andina). No es la política de Caja Huancayo ni de nadie.
Jev (TypeSafe)Código preparado para la API real (POST /v1/systemone). El formato del cuerpo y de la respuesta se tomó de documentación de terceros (DigitalOcean, LiteLLM, guías publicadas en 2026) y se prueba contra un servidor simulado. No se ejecutó contra la API real al preparar esta guía: tu primera ejecución de verificar_claves (paso 11) es también la prueba.
OpenAICódigo preparado para la API real (Responses API con JSON Schema estricto + text-embedding-3-small), probado con el SDK oficial contra respuestas HTTP simuladas. Tampoco se ejecutó con una clave real al preparar la guía.
Modo sin claveshash (embeddings léxicos) y mock (LLM de reglas fijas). Existen para que pytest corra sin red ni costo. No son inteligencia: el router hash acierta 62% en el set de prueba. Las salidas capturadas en esta guía usan este modo y lo indican.
Docker, Prometheus, GrafanaEjecutados de verdad en macOS (Docker Desktop) con el modo sin claves: contenedores sanos, Prometheus leyendo /metrics, las 23 consultas del tablero ejecutándose sin error.
Chat, escalamiento y aprobaciónRecorrido real en el navegador (modo sin claves): pregunta de seguimiento reformulada, formulario en el chat, analista viendo la conversación, decisión de vuelta en el chat.
Enmascarado de datos personalesProbado sobre el cuerpo HTTP que recibirían Jev y OpenAI (servidores simulados). Expresiones regulares: no detecta nombres propios.
WindowsLos comandos PowerShell se revisaron con un analizador automático (paso 14) y el código tiene pruebas de higiene para Windows. No se ejecutaron en un Windows real.

Requisitos

  • Python 3.10 o superior · Docker Desktop · un navegador · VS Code (recomendado).
  • Una clave de TypeSafe (TYPESAFE_API_KEY) y una de OpenAI (OPENAI_API_KEY). Sin clave de Jev puedes enrutar con embeddings de OpenAI (ROUTER_PROVIDER=embeddings).
  • Costo esperado del laboratorio completo: centavos de dólar (Jev cobra USD 0.042 por millón de tokens de entrada según su lista de precios publicada; OpenAI depende del modelo que elijas).
