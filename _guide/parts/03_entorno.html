Paso 2

Carpetas, entorno virtual, dependencias y .env

20 min

Preparas el esqueleto del proyecto y el entorno de Python. Al final tendrás tus dos claves guardadas donde corresponde: en .env, nunca en el código.

🪟 Windows: 7 trampas que conviene conocer ANTES de ejecutar nada
  1. Usa PowerShell (Windows Terminal → PowerShell). Los comandos están escritos para Windows PowerShell 5.1; también sirven en PowerShell 7. No los pegues en cmd.exe.
  2. python puede abrir la Microsoft Store. Verifica con py -3 --version; si falla, instala Python desde python.org marcando "Add python.exe to PATH".
  3. Carpeta corta, sin tildes ni espacios y fuera de OneDrive, por ejemplo C:\labs. OneDrive bloquea archivos de .venv mientras sincroniza.
  4. Política de ejecución: si Activate.ps1 "no está firmado", usa el comando de la variante B más abajo (solo afecta a esa ventana).
  5. && no existe en PowerShell 5.1. Un comando por línea.
  6. Activa "Extensiones de nombre de archivo" en el Explorador: si el Bloc de notas guarda .env.txt, la configuración nunca se leerá.
  7. Docker Desktop debe estar abierto (ícono de la ballena quieto) antes de cualquier docker compose, y usar el motor WSL 2.

¿Por qué __init__.py y python -m …? El archivo vacío convierte cada carpeta en un paquete. Con python -m app.ingesta Python agrega la raíz del proyecto al camino de importación y funcionan los from app.config import … en cualquier sistema operativo.

⚠ Seguridad de las claves
  • Escribe la clave sin comillas y sin espacios: OPENAI_API_KEY=sk-...
  • .env está en .gitignore: nunca lo subas a un repositorio, no lo pegues en un chat ni en una captura de pantalla.
  • Cambia ANALISTA_TOKEN por una frase propia: es lo que separa al asesor del analista.
  • Si una clave se filtra, revócala en la consola del proveedor (no basta con borrarla del archivo).
🪟 Si editas .env con el Bloc de notas se guarda en UTF-8 con BOM; si lo creas con echo X=1 > .env en PowerShell 5.1 se guarda en UTF-16. app/config.py (paso 3) entiende los dos formatos, pero verifica que el archivo se llame .env y no .env.txt.
¿No tienes clave de Jev? Según publicaciones de septiembre de 2026, TypeSafe pausó los registros nuevos (las cuentas existentes siguen funcionando). Usa ROUTER_PROVIDER=embeddings: se enruta comparando embeddings de OpenAI con los ejemplos de data/rutas.json. Todo lo demás del laboratorio es igual.
