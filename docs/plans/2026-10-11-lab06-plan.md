# Lab 06 — Plan de implementación

**Goal:** Laboratorio ejecutable: formulario del asesor → router Jev → agente de riesgo (RAG sobre PDF + OpenAI) → aprobación humana en HTML → respuesta al asesor; Prometheus + Grafana; guía HTML, análisis profundo, análisis Windows y zip.
**Architecture:** FastAPI + SQLite (`sqlite3`) + índice NumPy; proveedores intercambiables (jev/embeddings/hash, openai/mock); Docker Compose (app, prometheus, grafana).
**Tech Stack:** Python ≥3.10, fastapi, uvicorn, httpx, openai, numpy, pypdf, reportlab, prometheus_client, pydantic, python-dotenv, pytest.
**Spec:** `docs/specs/2026-10-11-lab06-design.md`

## Global Constraints
- Python 3.10+ (sin sintaxis 3.12-only); todo archivo escrito con `encoding="utf-8"` y `newline="\n"`.
- Comandos Windows: PowerShell 5.1, sin `&&`, `python -m pip`, `curl.exe`, sin `python -c`.
- Claves solo en `.env`; el DNI nunca sale hacia Jev/OpenAI; ningún nombre de modelo OpenAI inventado.
- Contenido del curso en español; datos ficticios declarados.

## Review Focus
1. Jev caído / 401 / 429 → la solicitud no se pierde (respaldo por embeddings + métrica). Prueba: `test_router.py::test_jev_falla_usa_respaldo`.
2. LLM devuelve JSON inválido o dictamen fuera de enum → OBSERVAR, no excepción. Prueba: `test_agente.py::test_llm_basura_observar`.
3. Analista decide dos veces / solicitud inexistente → 409 / 404. Prueba: `test_api.py`.
4. Monto/plazo/ingreso extremos (ingreso 0, plazo 0) → validación 422, sin división por cero. Prueba: `test_herramientas.py`, `test_api.py`.
5. Índice construido con otro embedder (dimensión distinta) → error claro al arrancar. Prueba: `test_rag.py::test_dimension_distinta`.
